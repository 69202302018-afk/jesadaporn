คู่มือแบบละเอียดยิบสำหรับเผยแพร่ Academic Portfolio บน GitHub

1

สร้าง Repository

เข้าไปที่ GitHub.com/new แล้วตั้งชื่อคลังข้อมูล เช่น academic-portfolio หรือ username.github.io

2

อัปโหลดไฟล์ index.html

นำซอร์สโค้ดในหน้านี้ บันทึกเป็นไฟล์ชื่อ index.html จากนั้นกด Add file > Upload files ขึ้นไปในคลังของคุณ

3

เปิดใช้งาน Pages

ไปที่เมนู Settings > Pages ในช่อง Branch เลือก main แล้วกด Save เว็บจะพร้อมใช้งานใน 1-2 นาที!

คำแนะนำ: คุณสามารถแก้ไขข้อมูลส่วนตัว ชื่อเรื่อง และลิงก์ได้โดยง่ายในไฟล์ index.html
